<h1> Neural Network Forward Propagation Animation </h1>
<p>
  Neural Network Forward Propagation <br />
  This script generates a smooth animated GIF visualizing forward propagation in a neural network.<br/>
  Features:Neurons light up sequentially as the signal travels from input to output<br/>
  Connections pulse with glowing blue highlights following the propagation wave<br/>
  Clean dark theme with smooth animation<br/>
  <br/>
  Network Architecture: [5, 8, 8, 3] (Input → Hidden → Hidden → Output)<br/>
  Built with: Matplotlib + imageio<br/>
  Perfect for: Project showcases, Explaining neural networks, Portfolio & documentation<br/>


  Dependancies:<br/>
  pip install numpy matplotlib imageio<br/>
  python nn_animation.py
</p>
